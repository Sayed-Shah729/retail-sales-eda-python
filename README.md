# 📊 Retail Sales Analysis - Sample Superstore

An end-to-end data analysis project to uncover sales trends and profit drivers in a retail business.

## About The Project
This project is a deep dive into the "Sample Superstore" dataset using Python. 
The main goal was simple: help the business understand where the money is coming from and where it's being lost.

I analyzed 4 years of sales data to answer key business questions and provide actionable insights.

## What You'll Find Here
- **Data Cleaning**: Cleaned and prepared 9994 rows of raw sales data
- **Sales Performance**: Identified top-selling categories, products, and regions  
- **Profitability Check**: Found which product categories are profitable vs loss-making
- **Customer Insights**: Analyzed buying behavior across different customer segments
- **Visual Storytelling**: Created clear charts with Matplotlib and Seaborn to explain the findings

## Tech Stack
`Python` `Pandas` `NumPy` `Matplotlib` `Seaborn` `Jupyter Notebook`
